# Сравнительный анализ алгоритмов машинного обучения: от собственной реализации до ансамблевых методов

## 📌 О проекте

Данный проект выполнен в рамках курсовой работы. Основная цель — не просто применить готовые модели машинного обучения, но и реализовать ключевые алгоритмы с нуля, верифицировать их на стандартных датасетах, а затем провести полный цикл обучения, гиперпараметризации и анализа на пользовательском датасете.

**Ключевые особенности:**
- 🏗️ **Собственная реализация** 8+ алгоритмов ML (без использования высокоуровневых библиотек для обучения)
- ⚖️ **Сравнение** кастомных моделей с эталонными библиотеками (`scikit-learn`)
- 🔍 **Полный цикл гиперпараметризации** (GridSearch, RandomSearch)
- 📊 **Углубленная визуализация** (кривые обучения, анализ остатков)

| Порядок | Ноутбук | Описание |
|---------|---------|----------|
| 1 | `Preprocessing.ipynb` | Загрузка данных, очистка, обработка пропусков, нормализация, разделение на train/valid/test |
| 2 | `LinearModels.ipynb` | Линейная регрессия, Lasso, Ridge, ElasticNet, PolynomialFeatures |
| 3 | `KNN_n_Trees.ipynb` | KNN, Decision Tree |
| 4 | `SVM.ipynb` | Метод опорных векторов |
| 5 | `Ensembles.ipynb` | Bagging, Boosting, Voting, Stacking, RandomForest |
| 6 | `Analysis.ipynb` | Попытка немного оптимизировать при помощи логарифмирования целевой переменной|

> В каждом ноутбуке реализованы модели с нуля, выполнено сравнение с библиотечными аналогами (`sklearn`), проведена гиперпараметризация и выполнено предсказание экзаменационного балла на тестовой выборке.
